Privacy Policy

Last updated: October 30, 2026

This policy describes how Shorts Farm Uploader ("the tool") accesses, uses, stores, shares and deletes data. The tool is a private, internal application used only by its owner to upload their own videos to their own YouTube channels. It has no third-party users.

YouTube API Services

The tool uses YouTube API Services (YouTube Data API v3). By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy: http://www.google.com/policies/privacy.

Information the tool accesses and collects

With the owner's consent given through Google OAuth, the tool requests two permissions:

  • youtube.readonly — to read the connected channel's ID, title, handle and statistics (subscribers, videos, views), and the titles, IDs and processing status of videos already uploaded to that channel.
  • youtube.upload — to upload the owner's videos and set their title, description, tags, privacy status and thumbnail.

The tool does not request access to comments, messages, subscribers' personal data, analytics, monetization or any other Google service. It does not access or collect data of other YouTube users.

How the information is used

The information is used only to show the owner which channels are connected, to upload the owner's videos to the chosen channel, to show the upload and processing status, and to avoid uploading the same video twice. It is not used for advertising, profiling, sale or any other purpose.

Storage

  • OAuth refresh tokens are stored only locally, in a file on the owner's own computer. They are not uploaded to any server, database or cloud service operated by the tool.
  • A local log on the owner's computer records, for each uploaded video, its title, YouTube video ID, link, privacy status and upload time.
  • Video files and their metadata stay on the owner's computer until they are sent directly to YouTube.
  • The tool's dashboard runs on localhost only. It does not set advertising or tracking cookies and does not store data in the browser.

Sharing

Data is not sold, shared with, disclosed to or transferred to any third party. The only external service the tool communicates with for YouTube data is Google / YouTube, through the official YouTube Data API.

Retention and deletion

  • Data retrieved from the YouTube API (channel statistics, video lists, processing status) is shown in the dashboard and is not stored, except the video ID, title, link and time in the local upload log.
  • The owner can delete all stored data at any time by deleting the local token file and upload log. The dashboard's "Disconnect" button deletes a channel's stored token.
  • If access is revoked in the Google account, the stored token stops working and is deleted the next time the tool detects this, and in any case within 7 days.
  • To ask for deletion of any data related to the tool, write to sunnat.shukhratov@gmail.com; the request is completed within 7 days.

Revoking access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions — select "Shorts Farm Uploader" and choose "Remove access". After revocation the tool can no longer access the YouTube account. The dashboard also shows this link.

Changes

If this policy changes, the updated version is published on this page with a new "Last updated" date.
