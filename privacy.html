Privacy Policy

Last updated: October 30, 2026

This policy describes how Shorts Farm Uploader ("the tool") handles data. The tool is a private, internal application used only by its owner to upload their own videos to their own YouTube channels. It has no third-party users.

Data the tool accesses

Through the YouTube Data API, with the owner's consent given via Google OAuth, the tool uses:

  • Basic information about the owner's own YouTube channels (channel ID and title), to choose where to upload.
  • The ability to upload videos and set their metadata (title, description, tags, thumbnail, privacy status, publish time).
  • Information about videos already uploaded to the owner's channels, to manage them.

The tool does not access, collect or process any data of other YouTube users, and it does not use Google user data for advertising or any purpose other than uploading and managing the owner's own videos.

Storage of tokens and data

OAuth access and refresh tokens are stored only locally, on the owner's own computer. They are not uploaded to any server, database or cloud service operated by the tool. Video files and metadata stay on the owner's computer until they are sent directly to YouTube.

Sharing

Data is not sold, shared with or transferred to any third party. The only external service the tool communicates with is Google / YouTube, through the official YouTube Data API.

Revoking access

Access can be revoked at any time:

  • Open Google Account → Security → Third-party apps with account access, select "Shorts Farm Uploader" and choose "Remove access".
  • Delete the locally stored token files from the computer where the tool runs.

After revocation the tool can no longer access the YouTube account.

YouTube and Google policies

The tool uses YouTube API Services. By using it you are also subject to the YouTube Terms of Service and the Google Privacy Policy.

Changes

If this policy changes, the updated version will be published on this page with a new "Last updated" date.
