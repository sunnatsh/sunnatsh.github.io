NG-content team

Developed with YouTube

NG-content team is a private, internal tool used by its owner to upload their own videos to their own YouTube channels. It uses YouTube API Services (YouTube Data API v3).

What it does

  • Runs locally on the owner's computer as a small web dashboard (localhost).
  • Shows the owner's connected YouTube channels and the queue of videos produced for each channel.
  • Uploads the owner's own videos with a title, description, tags and thumbnail, and shows their processing status.
  • Reads the list of videos already on the owner's channels so the same video is never uploaded twice.

Who can use it

The tool is not a public service and is not offered to anyone else. It is used only by its owner with the owner's own Google accounts. No third-party users sign in to it, and it does not access anyone else's YouTube data.

Google and YouTube data

How the tool accesses, uses, stores and deletes YouTube data is described in the Privacy Policy. Rules for using the tool are in the Terms of Service. By using the tool you agree to the YouTube Terms of Service and the Google Privacy Policy.

Access can be revoked at any time on the Google security settings page.
